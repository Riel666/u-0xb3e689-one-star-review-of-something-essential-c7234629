# Sleep, No Refund

A deadpan one-star review of an everyday essential: sleep, which takes eight hours a night and offers no refund for nightmares.

## The text

One star. Sleep takes eight hours a night, offers no refund for nightmares, and uninstalls itself the moment I need it most.

## How to run

Python 3.13, standard library only, no network.

```sh
python3 main.py
```

Writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
